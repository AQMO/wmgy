# 界面效果图汇总

> 万亩果园多商户果园小店平台 — 后台 PC 端（管理员）与小程序用户端（单果园版）预期效果图。
> 所有效果图与已实现代码一一对应，设计变量与 `miniprogram/src/pages.json`、`uni.scss` 保持一致。

## 设计语言

| 项目 | 取值 | 说明 |
|---|---|---|
| 主色 | `#3B6D11` / `#639922` | 果园绿，按钮、导航、选中态 |
| 浅绿底 | `#EAF3DE` | 标签、说明条、承诺区 |
| 价格色 | `#D85A30` | 橙红，符合国内电商价格习惯 |
| 页面底 | `#FAFAF6` + 白卡 `0.5px #EFEDE6` | 扁平无阴影，圆角 10px |
| 状态色 | 橙 `#BA7517`（待审/待发货）、红 `#A32D2D`（风险/拒绝）、绿 `#3B6D11`（营业中/通过） | 与后端状态枚举对应 |

## 一、后台 PC 端（对应 `frontend/src/views/admin`）

### 1. 数据概览 / 商家管理（`Dashboard.vue` / `MerchantManage.vue`）

![后台仪表盘与商家管理](png/01-admin-dashboard.png)

- 四项核心指标卡：今日 GMV、今日订单、入驻商家（含待审核角标）、今日访问（PV/UV）
- 近 7 日成交柱状趋势 + 待办事项（入驻审核、物流预警、提现申请、聊天风险消息）
- 商家管理表格：状态徽标（营业中/待审核）、本月流水、通过/驳回审核操作

### 2. 聊天监控 / 流量监控（`ChatMonitor.vue` / `TrafficMonitor.vue`）

![聊天监控与流量监控](png/02-admin-monitor.png)

- 聊天监控：左侧会话列表（全部/风险双 Tab、未读与风险角标），右侧只读对话流，风险词命中红标 + 系统提示条，支持「警告双方 / 冻结会话」；右上角 WebSocket 实时连接状态
- 流量监控：PV/UV/平均停留/转化率四指标，24 小时访问柱状图（对应 `t_visit_log` 小时级埋点），热门页面排行

## 二、小程序用户端 · 单果园版（对应 `miniprogram/src/pages`）

### 3. 首页 / 商品详情（`pages/home` / `pages/product`）

![小程序首页与商品详情](png/03-mini-home-product.png)

- 首页：果园身份卡（园名、产地、经营年限、评分、营业中徽标）+ 园主公告 + 四宫格入口 + 「店长推荐」双列商品流；无任何平台商城/多店铺元素
- 商品详情：果园实拍主图、划线价、服务标签、绿底「本园承诺」、规格选择、园主在线卡；底部「客服 / 购物车 / 加购 / 立即购买」

### 4. 购物车 / 确认订单（`pages/cart` / `pages/confirm`）

![小程序购物车与确认订单](png/04-mini-cart-confirm.png)

- 购物车：满 ¥99 包顺丰进度提示、扁平单列（无店铺分组）、单层勾选、数量步进器
- 确认订单：「本单由万亩果园直接采摘发货」说明条（无拆单）、默认地址卡、优惠券与买家留言、微信支付按钮
